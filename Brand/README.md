# AirStrum brand assets / 品牌资产

- `logo.svg`: square app mark / 方形应用标志
- `brand.svg`: bilingual repository banner / 双语项目横幅

The assets intentionally use the same dark navy and mint signal language as
the native app UI. They are source SVGs so they can be exported to PNG at any
required size without losing sharpness.

这些资产与原生 App 使用同一套深海军蓝与薄荷信号色。保留 SVG 源文件，方便按
需要导出任意尺寸的 PNG，避免缩放失真。
